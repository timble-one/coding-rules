# Look and Feel
- The Application must be fancy but minimal and not contains some generic bla-bla text.
- A favicon must be implemented.

## Style
The UI of the app must be styled according to these instructions:

- Direction: clean, minimal, quietly friendly. Clear hierarchy, useful content, consistent spacing.
- Palette: white #FFFFFF, cool gray background #F8FAFC, dark text #172033, muted text #64748B, blue accent #2563EB. No beige or brown tones; maintain accessible contrast.
- Type: system sans-serif throughout, including headings. Body 14–16px; headings 24–30px, medium or semibold. Sentence case.
- Shape: 10–12px corners on controls, 14–16px on panels. Rounded without making every element a pill.
- Layout: tidy alignment, an 8px spacing rhythm, comfortable breathing room. Group related content; use cards only when they help.
- Detail: light 1px borders; mostly flat surfaces. Use a faint shadow only for floating elements. Simple line icons, subtle hover states, visible keyboard focus. Skip gradients, decorative flourishes, and oversized headlines.
